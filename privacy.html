Privacy Policy — All In Records Uploader

Last updated: 2026-10-10

All In Records Uploader (“the Tool”) is a private, single-user internal tool operated by Myungchul Kim (All In Records). It is used only by its owner to upload and schedule self-produced videos to the owner’s own YouTube channels. It is not offered to the public.

1. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

The Tool’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

2. Information the Tool accesses and collects

  • Google OAuth authorization for two scopes only:
    • https://www.googleapis.com/auth/youtube.upload — to upload videos to the authorized channel.
    • https://www.googleapis.com/auth/youtube.readonly — used only (1) to confirm which of the owner's own channels an authorization belongs to (channel name and ID, via channels.list with mine=true), and (2) to re-check the upload and privacy/scheduling status of videos that the Tool itself uploaded, so that stored information stays current.
    The Tool does not read viewer data, comments, subscribers, analytics, or any other Google account data, and does not read videos it did not upload.
  • OAuth tokens issued by Google, stored only on the owner’s own computer.
  • Upload results and status returned by the API for videos uploaded by the Tool (video ID, upload status, privacy status and scheduled publish time), used only to confirm uploads and show their current status to the owner.

The Tool does not collect personal information about viewers or any other users, and does not use cookies or analytics.

3. How the information is used

The information is used only to upload and schedule videos that the owner has produced and approved, to the owner’s own channels, and to show the owner the current status of those uploads. It is not used for advertising, profiling or any other purpose.

4. Sharing

The Tool does not sell, share, or transfer any information to third parties. Videos and their metadata are sent only to YouTube through the YouTube API Services.

5. Storage, retention and deletion

  • OAuth tokens are stored locally on the owner’s computer and are deleted when access is revoked.
  • Information returned by the YouTube API (video ID, upload status, privacy status, scheduled publish time) is stored in a single local file. It is refreshed from the API at least every 30 days, and any item that cannot be refreshed within 30 days is deleted. Videos that no longer exist on YouTube are removed from storage.
  • The Tool checks at least every 30 days that the owner’s authorization is still valid; if it is not, all stored API data for that channel is deleted.
  • If authorization is revoked, the Tool stops all access and deletes stored tokens and related data within 7 days (within 30 days if revoked through the Google security settings page).
  • Deletion can be requested at any time using the contact below and will be completed within 7 days.

6. How to revoke access

You can revoke the Tool’s access to your Google account at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
